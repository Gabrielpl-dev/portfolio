# Gabriel — Portfólio Pessoal

Meu portfólio pessoal. Construído com React + Vite.

Foco em **harness engineering** — a camada em volta do modelo que torna sistemas de AI confiáveis, mensuráveis e depuráveis.

## Stack

- React 19 + Vite
- AOS (Animate on Scroll)
- Google Fonts (Fraunces + Inter)
- CSS puro (sem framework)

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
